# Your restaurant logo

1. Put your logo file in **this folder** (`public/images/branding/`).
2. Name it **exactly**: `restaurant-logo.png`
3. Refresh the website (Ctrl+F5). That's it: no code changes needed.

To replace the logo later, overwrite the file with the same name. To go back to the text "VINDU HAVELI", delete (or rename) the file.

## Good logo files
- PNG with a **transparent background** works best on the dark theme.
- Around 600–1000 px wide. The logo is never stretched or cropped; it is only scaled down to fit (navbar, footer, login, receipts and so on).
- If the file is missing or broken, the site automatically shows the gold "VINDU HAVELI" text instead, so you never see a broken image.
