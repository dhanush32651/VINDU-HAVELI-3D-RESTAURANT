# Background videos

Put your video files **in this folder** (`public/videos/`) using **exactly** these names (lowercase):

| File name | What it should show | Where it plays |
|---|---|---|
| `cooking-process.mp4` | Chef cooking | Home page hero · "Order Food" card · Breads category |
| `restaurant-interior.mp4` | Restaurant interior | Login/Signup page · Book Dine page · "Reserve a table" and "About" sections · "Book Dine" card |
| `biryani.mp4` | Biryani cooking / serving | Biryani category · Home "3D Showcase" section |
| `pizza.mp4` | Pizza preparation / cheese pull | Pizzas category |
| `sandwich.mp4` | Sandwich preparation | Sandwiches category |
| `burgers.mp4` | Burger preparation | Burgers category |
| `starters.mp4` | Starters and appetizers | Starters category |
| `desserts.mp4` | Desserts | Desserts category |
| `cool-drinks.mp4` | Cold drinks / beverages | Soft Drinks and Mocktails categories |
| `grilled-chicken.mp4` | Grilled chicken | Main Course category |

## Tips
- Use **MP4 (H.264)** files. Keep each under **8 MB** (10–20 seconds is plenty) so pages load fast.
- No sound is needed: videos always play muted, loop forever, and have no controls.
- Landscape (16:9) works best. The video is cropped to fill the area without stretching.
- Missing a file? No problem. That section simply keeps its normal look (or shows the dish photo) until you add the video. Nothing breaks.
- To change which video a section uses, edit `data/videos.ts`.
- After adding or replacing a file, refresh the browser (Ctrl+F5).
